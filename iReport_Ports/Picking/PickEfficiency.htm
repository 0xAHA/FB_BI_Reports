📖 How this report works

What it shows

How long picking took: every pick that was finished in the date range, with when it was started, when it was finished and the minutes in between, grouped by the pick's user. It is the BI version of the standard Pick Efficiency report and reads the same data the same way.

How it is measured

Minutes are whole minutes from the pick's start to its finish, rounded down (2 min 59 s counts as 2), as the standard report counts them.

Each user's row gives Orders, the number of picks, and Average Time, the average of their minutes. A pick with no start time is listed and counted, but has no minutes and stays out of the average; the user's row says how many there are.

Using it
  • Filter changes apply straight away. The dates are the day each pick was finished; both end days count in full. Choosing no users or location groups means all of them.
  • Click a user's row to show or hide their picks; Expand / Collapse do every user. Collapsed is the standard report with Show Details off: user totals only. It is remembered with your filters.
  • Click a column heading to sort the picks within each user (again to reverse, a third time for the standard order): Minutes puts the slowest or quickest first. Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: average (or total, lowest, highest) minutes or the number of picks by any two of user, location group, pick type, date finished or started (by day, week, month, quarter or year), weekday and a duration band (0–15 min … over 24 h). It opens on each user's average minutes per week. Click a figure to see the picks behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so picks (whole users) with a Load all button; the footer then covers the picks shown.
