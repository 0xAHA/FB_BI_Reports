📖 How this report works

What it prints

A barcode label for each location: its tag number as a barcode, the location group, the location's name and the tag number (the number Fishbowl scans for the location). It replaces the standard Location Barcode, 2x4 Location Barcode Avery, Location Barcode One Off, 2x4 One Off and 4x6 One Off labels.

Locations (left): every active location in the location groups picked (only yours are listed) whose name matches the Location box (% is a wildcard; empty is every location), ordered by location group and then by the Sort by choice; or a list of locations you choose. Copies of each location repeats every label.

The preview shows one page at a time, as Fishbowl's report viewer: a sheet, or one label on a label printer. Page through with the arrows above it.

The sheet
  • The pills under the header are the sheets and label printers. Pick the one in the printer.
  • Sheet setup changes the paper, how many labels across and down, the page margins and the gaps between labels, and saves it as your own setup (an admin can add it for everyone). Measure your sheet with a ruler, or use the numbers on its packet.
  • From a Word template: pick the label maker's Word template for your sheet (an Avery .doc or .docx), or drop the file anywhere on this page. Its page size, margins, label size and gaps fill a new sheet setup; check it with a Test sheet, then save it.
  • Test sheet prints numbered outlines of every label: hold it against a sheet of labels to the light to check it lines up.
  • Start at label skips used labels on a partly used sheet. Fill: across fills each row first; down fills each column first, as the standard sheets did.
The label
  • Each field takes its Height share of the label. Text is as large as its lines allow (Auto), or at most the size picked; long text shrinks and wraps onto the Lines allowed. Tick Fixed to keep the size picked: what doesn't fit is cut short with …
  • The barcode's type: Code 128 (the standard reports' barcode; any text), Code 39 (capitals, digits and - . $ / + % space), EAN-13 / UPC-A (12 / 11 digits; the check digit is added), QR Code and Data Matrix (square; any text). A tag number a type can't carry shows a red box instead, and is listed under Printing.
  • Tag number is the standard reports' Show Tag option: untick it to leave the number off under the barcode. Description is the location's description, off to start, as the standard labels don't print it.
  • Bold and alignment are per field; untick a field to leave it off. Drag a field by its handle (☰, on the left) to change the order.
  • A warning shows when a barcode would be too dense to scan reliably: give it more width (fewer labels across).
  • The preview zooms with − / + or Ctrl + mouse wheel. 100% is life size on a standard display (single labels open at it); Fit shows the whole page.
  • Print pages prints part of the job. A big job (hundreds of pages; on a label printer every label is a page) is flagged under Printing with how long it may take; Print in parts sends it in pieces, setting up the next part after each.
  • Print opens the labels in a print window, one sheet per page at the sheet's size. In the print dialog choose the label printer or the paper tray with the labels, scale 100% (actual size), no margins.
