📖 How this report works

What it prints

Labels pre-printed with a tracking value (a lot number, a serial number…), to stick on stock before it is received or added: each label has the value as a barcode with the value under it. It replaces the standard New Tracking, New Tracking One Off, New Tracking Incremental and New Tracking Incremental One Off labels.

Part (optional): pick an existing part and the label can also carry its part number, description and the part number's barcode, and the tracking's name from the part's primary tracking ("Lot#: A12"). Tick the fields you want in the Label section. A part number that isn't an active part prints nothing until it is corrected or cleared.

Tracking lists the part's tracking types. A date (an expiration date, a best-before date) gets a date picker and every label carries that date. Picking a tracking sets Print to suit it (serial numbers count up, everything else repeats); change it if you need to. When the tracking has a Next Value in Fishbowl, Start at Fishbowl's next value starts the labels there, so you can label a batch before the work order is finished. Printing doesn't change the next value in Fishbowl.

Tracking (left), Print: The same value on every label, or Values counting up from the first value. Number to print is how many labels.

This report never changes anything in Fishbowl. Printing doesn't record or reserve the values: type them in Fishbowl when the inventory is received or added, as with any tracking value.

The preview shows one page at a time, as Fishbowl's report viewer: a sheet, or one label on a label printer. Page through with the arrows above it.

Counting up

The values count up the way Fishbowl's standard report counts, like a car's odometer:

  • The last letter or digit goes up by one: 0 to 9, A to Z, a to z. After 9, Z or z it goes back to 0, A or a and the character before it goes up (it carries).
  • Other characters (spaces, - . / _, accented letters) stay as they are and are skipped over.
  • When every character carries, one is added at the front: 1 for a value starting with a digit, A for a capital, a otherwise.
  • Zeros at the front are kept: SN0009 → SN0010; A9 → B0; ZZ → AAA.
  • Letters count up too: after LOT-999 comes LOU-000. A note under Printing says when the values run out of digits like this: start with more zeros (LOT-0001) to stay on LOT-.

The summary under Printing shows the first and last values.

The sheet
  • The pills under the header are the sheets and label printers. Pick the one in the printer.
  • Sheet setup changes the paper, how many labels across and down, the page margins and the gaps between labels, and saves it as your own setup (an admin can add it for everyone). From a Word template reads a label maker's Word template (an Avery .doc or .docx; or drop the file on this page) into a new setup.
  • Test sheet prints numbered outlines of every label: hold it against a sheet of labels to the light to check it lines up.
  • Start at label skips used labels on a part-used sheet. Fill: across fills each row first; down fills each column first, as the standard sheets did.
The label
  • Each field takes its Height share of the label. Text is as large as its lines allow (Auto), or at most the size picked; long text shrinks and wraps onto the Lines allowed. Tick Fixed to keep the size picked: what doesn't fit is cut short with …
  • The barcode's type: Code 128 (the standard reports' barcode; letters, digits and punctuation, no accented letters), Code 39 (capitals, digits and - . $ / + % space), EAN-13 / UPC-A (12 / 11 digits), QR Code and Data Matrix (square; any text). A value a type can't carry shows a red box instead, and is listed under Printing.
  • Bold and alignment are per field; untick a field to leave it off. Drag a field by its handle (☰, on the left) to change the order.
  • A warning shows when a barcode would be too dense to scan reliably: give it more width (fewer labels across) or use a shorter value.
  • The preview zooms with − / + or Ctrl + mouse wheel. 100% is life size on a standard display (single labels open at it); Fit shows the whole page.
  • Print pages prints part of the job; a big job offers Print in parts. Print opens the labels in a print window, one sheet per page at the sheet's size: choose the label printer or the tray with the labels, scale 100% (actual size), no margins.
