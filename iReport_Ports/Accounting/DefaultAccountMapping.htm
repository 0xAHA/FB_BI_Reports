📖 How this report works

What it shows

Each of Fishbowl's default accounts (Accounts Receivable, Inventory Asset, Shipping Income…) and the account in your accounting system it posts to, as set up in Fishbowl's accounting settings. It is the BI version of the standard Default Account Mapping report and reads the same data the same way.

As in the standard report, a default that isn't mapped to an account is left out. Show defaults with no account lists those too, so you can see what still needs setting up.

Using it
  • Filter changes apply straight away. Account contains matches either column.
  • Show account number and type adds the mapped account's number and type.
  • Click a column heading to sort (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • Excel saves the rows shown, with the account number and type.
