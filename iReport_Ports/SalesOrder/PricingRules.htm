📖 How this report works

What it shows

Every pricing rule set up in Fishbowl, described in words: which products and customers it applies to, how it changes the price, any rounding, the dates and quantities it is limited to, whether it is a Tier 2 rule and whether it is applied automatically. It is the BI version of the standard Pricing Rules report and uses the same words.

Using it
  • Type part of a rule's name to list only those rules (% is a wildcard). Tick Show inactive to add the inactive rules: they are marked "(inactive)".
  • Click a product or customer to open it in Fishbowl.
  • Click a column heading to sort (again to reverse, a third time for name order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: the number of rules, or their percent or amount, by any two of type, base amount, product scope, customer scope, tier, auto-apply, whether dates or quantities limit the rule, and active. It opens on the rule count by type and customer scope. Click a figure to see the rules behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages: the standard report's rule cards, two across. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
