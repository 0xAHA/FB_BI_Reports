📖 How this report works

What it shows

Total Product Sales: each product's gross sales posted in the date range, greatest first. With All dates it is the gross sales to date. It is the BI version of the standard TPS Report and reads the same data the same way.

The figures
  • Sales adds up, for each posted sales order line of the product, the quantity posted × the line's unit price, plus the line's adjustment. Amounts are in the home currency.
  • A sale counts when it was posted (the items fulfilled), not when it was ordered.
  • Only orders whose salesperson is a Fishbowl user count (as the standard report): orders without one, or whose salesperson is no longer a user, are left out.
Using it
  • Filter changes apply straight away. Include cover sheet adds the standard report's confidential cover page to the PDF view and Print.
  • Click a column heading to sort (a third click for the report's order); drag a heading to move the column, its right edge to resize it.
  • The App / PDF buttons switch between this view and printable pages laid out like the standard report. Print prints those pages.
