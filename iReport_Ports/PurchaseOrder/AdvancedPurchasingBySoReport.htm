📖 How this report works

What it shows

Every sales order line for an inventory part, with the stock of that part at the order's location group: what is on hand, what all open orders have allocated, what is on order, and whether the part is short. It is the BI version of the standard Advanced Purchasing By Sales Order report.

The figures
  • Qty Needed: what the line still has to ship, in the part's unit (UOM). A fulfilled, closed, voided or cancelled line, and a credit return, need nothing.
  • Available = On Hand − Total Allocated − Not Available + Drop Ship. Short shows it (red) when it is below zero. An estimate isn't allocated yet, so its own Qty Needed is taken off too.
  • Order Date = the line's scheduled date − the default vendor's lead time: order by then to have the stock in time. Red when the line still needs stock that the stock at the location group doesn't cover. Order date from switches to the standard report's Date Created − lead time.
Using it
  • Filter changes apply straight away. SO number takes % as a wildcard; blank lists every SO. The date range is on the SO's Date Created (standard default This month).
  • Group by Part turns the report into a purchase list: each part at each location group with its total need, stock, Short and earliest order date, and the sales order lines under it.
  • Click a group's row to show or hide its lines; Expand / Collapse do every group.
  • Click a column heading to sort the lines within each group (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: Qty Needed, Line Qty or the number of lines by any two of default vendor, part, SO #, customer, SO status, location group, buy state and the dates. It opens on default vendor + part × buy state (Short / Covered / Nothing left): what is short, by vendor. Pick Order Date (by month or week) for when to order it. Click a figure to see the lines behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so lines (whole sales orders) with a Load all button.
