📖 How this report works

What it shows

Every part each work order consumes, with the stock of that part at the work order's location group: what is on hand, what all open orders have allocated, what is on order, and whether the part is short. It is the BI version of the standard Advanced Purchasing By Work Order report.

The figures
  • Qty Needed: what the item still has to consume (target − used), in the part's unit (UOM). A fulfilled work order, or one of a fulfilled, closed short or voided MO, needs nothing.
  • Available = On Hand − Total Allocated − Not Available + Drop Ship. Short shows it (red) when it is below zero. An open work order's parts are already in Total Allocated.
  • Order Date, by Calculate order date from: MO Date Scheduled − (Lead Time + the BOM's estimated time), or WO Date Scheduled Start − Lead Time. Red when the item still needs stock and the part is short.
  • Each work order row shows its Start Time (Date Scheduled Start), the BOM's Estimated Time and its End Time (Date Scheduled).
Using it
  • Filter changes apply straight away. MO number takes % as a wildcard; blank lists every MO. The date range is on the MO's Date Scheduled (standard default This month).
  • Group by Part turns the report into a purchase list: each part at each location group with its total need, stock, Short and earliest order date, and the work order lines under it.
  • Click an MO's row to show or hide its work orders; Expand / Collapse do every group.
  • Click a column heading to sort the lines within each work order (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: Qty Needed, Line Qty or the number of lines by any two of default vendor, part, part type, MO, WO, status, location group, buy state and the dates. It opens on default vendor + part × buy state (Short / Covered / Nothing left): what is short, by vendor. Pick Order Date (by month or week) for when to order it. Click a figure to see the lines behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so lines (whole manufacture orders) with a Load all button.
