📖 How this report works

What it shows

What was built: every finished part of every work order that was finished (status Fulfilled) in the date range, grouped by part. It is the BI version of the standard Production Report and reads the same data the same way.

Quantities

Each work order line shows the quantity it finished in its manufacture order's UOM. The part's row adds them up in the part's own UOM, converting where the units differ. A line whose UOM has no conversion to the part's is left out of the total and flagged in amber on the part's row.

A work order finished in several goes lists one line per finish.

Using it
  • Filter changes apply straight away. The dates are the day each work order was finished; both end days count in full.
  • Click a part's row to show or hide its work orders; Expand / Collapse do every part. Collapsed is the standard report with Show Data off: part totals only. It is remembered with your filters.
  • Click a column heading to sort the work orders within each part (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: the quantity built (in each part's UOM), the number of work orders or lines, by any two of part, UOM, production date (by day, week, month, quarter or year), location group and manufacture order. It opens on parts built per month. Click a figure to see the lines behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so lines (whole parts) with a Load all button; the footer counts then cover the lines shown.
