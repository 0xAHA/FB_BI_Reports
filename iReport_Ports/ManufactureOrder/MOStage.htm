📖 How this report works

What it shows

Where each manufacture order's stages are up to: every work order of every stage, with its stage level, quantity and status. It is the BI version of the standard Manufacture Order Stage report and reads the same data the same way.

One row per work order

An MO's stages are its build lines (one per bill of materials it makes). Each row is a work order made for a stage, so a stage split into several work orders has a row for each. A stage without a work order yet isn't listed, as in the standard report. Status is the work order's: Entered Started Fulfilled.

Using it
  • Filter changes apply straight away. MO number takes % as a wildcard (20% = every MO starting 20); blank lists every MO.
  • The date range is on the MO date you pick (Date Issued by default). The standard default, This month, shows only MOs issued this month: pick All dates for every MO with that date. An MO without it (e.g. not completed yet, with Date Completed) is never listed.
  • Click an MO's row to show or hide its work orders; Expand / Collapse do every MO. The MO row counts its work orders and shows the MO's status and date.
  • Click a column heading to sort the work orders within each MO (again to reverse, a third time for the standard order). Status sorts in workflow order. Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: total Stage Qty, the number of work orders or the number of MOs by any two of stage name, stage level, WO status, MO status, MO # and the MO's date. Stage name × WO status shows how much of each product is at each status. Click a figure to see the work orders behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so work orders (whole MOs) with a Load all button.
