📖 How this report works

What it shows

Every shipment shipped (status Shipped) for the orders issued and shipped in the chosen periods: the order, who it went to, when the order was issued and when it shipped, how many days that took, and the carrier. It is the BI version of the standard Shipment History report and reads the same data the same way.

The rows
  • One row per shipment. Days to Fulfill is the calendar days from the order's issue date to the ship date.
  • Sales order shipments show by default; tick Include purchase orders / transfer orders for the others.
  • Show shipment number shows the shipment number instead of the order. Click a number to open the order or the shipment.
Using it
  • Both periods start on Today, as in the standard report: pick a quick range or type the dates. Both end days count in full.
  • Sort by sets the report's order. Click a column heading to sort on screen (again to reverse, a third time for the report's order); drag a heading onto another to move the column; drag a heading's right edge to resize it.
  • The Table / Pivot selector switches to a pivot: the number of shipments or the days to fulfil (average, lowest, highest…) by carrier, order type, ship-to or month issued / shipped.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. Print prints those pages.
  • A very large result shows its first 10,000 shipments with a Load all button.
