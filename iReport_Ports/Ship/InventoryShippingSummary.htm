📖 How this report works

What it shows

Every product shipped on a sales order in the period: how many, when, where it went (name, address, city, state, zip), the carton's tracking number, the carrier and the customer. It is the BI version of the standard Inventory Shipping Summary report and reads the same data the same way.

The rows
  • One row per item shipped, with the tracking number of the carton it went in. Quantities are in the item's shipped UOM (the report shows no UOM, as the standard one).
  • Only sales order shipments: the customer filter needs one.
  • Lines without a ship-to state are left out unless Show items with no state is ticked.
Using it
  • The period starts on This month, as in the standard report. The name, address, city and zip boxes match any part of the value; product number and state code take % as a wildcard.
  • Columns shows or hides each column, as the standard report's column options. Click a column heading to sort (again to reverse, a third time for the report's order); drag a heading onto another to move the column; drag its right edge to resize it.
  • The Table / Pivot selector switches to a pivot: the quantity, lines or shipments by product, customer, state, city, carrier, ship-to or month shipped.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. Print prints those pages.
  • A very large result shows its first 10,000 lines with a Load all button.
