📖 How this report works

What it shows

Every address on your customers' accounts, with the customer's contact details. It is the BI version of the standard Customer Address List and reads the same data the same way.

A job's addresses show as Parent:Name. Click a name to open the customer.

Contacts

Under each address are the customer's contacts of the chosen Contact type (Main by default): phone numbers, emails and so on. They belong to the customer, so every address of a customer lists the same ones, as in the standard report.

Groups

With Show groups on, addresses are listed under each customer group; a customer in three groups appears under all three. Customers in no group are under No Group. Click a heading to fold it away.

Pick groups under Customer groups to list only those (include No Group for customers in none). Leave it empty for every customer.

Using it
  • Filter changes apply straight away.
  • State matches the state code (QLD, CA…) and Zip the postcode; use % or * as a wildcard (41% = every zip starting 41).
  • Cards is the standard label sheet; Table lists one address per row. The PDF view and Print are the 3-column sheet; Excel is one row per address.
  • In the Table view, click a column heading to sort the addresses (within each group when Show groups is on; again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it. While the Table view is shown, the PDF label sheet and Excel follow its sort (sort by Zip for a mail-out).
  • Pivot counts the addresses by any two of customer group, customer, address type, state, country, city, zip and status. Click a count to see the addresses behind it. Print, PDF and Excel follow the pivot on screen. With Show groups on, an address counts once under each of its customer's groups, as the list shows it.
  • A very large result shows its first 10,000 addresses with a Load all button.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
