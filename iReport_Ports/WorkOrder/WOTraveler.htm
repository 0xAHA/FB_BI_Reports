📖 How this report works

What it shows

The traveler of one work order: the paper that goes with the job. Its header (BOM, customer and sales order, scheduled dates, category, priority, location, status), its note, the optional instructions, and its Finished Goods and Raw Goods with their quantities. It is the BI version of the standard Work Order Traveler and reads the same data the same way.

  • BOM Qty is each item's quantity per unit built; WO Qty its total for the work order.
  • Printed, Finished, Used and Scrapped are blank columns to write in. On screen they show what Fishbowl has recorded once the work order is started.
  • Tracking: while the work order is open, each tracked item gets a line per tracking type (lot, expiry…) to write in; once it is fulfilled, the values recorded.
Choosing the work order
  • Open Filters and type a WO number, an MO number or the finished good's part number: the list shows the matching work orders with their status, created date and quantity. The status and Created chips narrow it; with the box empty (or the ▾ button) it lists the newest. The arrows step to the previous / next work order within those chips.
  • The report opens on the work order you looked at last (else the newest open one). When the BI report's Work_Order setting names a work order, it opens on that one first.
  • Opened from a work order (the Work Order module's Apps menu), the report shows that work order and the picker is hidden, so it can't be changed by accident.
Using it
  • Every option of the standard report is in Filters (instructions, header, footer) and Settings (title, the column switches); changes apply straight away. The standard report's saved options are the starting point (marked stock); Reset options goes back to them.
  • Instructions: none, the work order's own steps, or the BOM's instructions, printed above the finished goods.
  • Click a WO, MO, sales order or part number to open it in Fishbowl.
  • Click a Finished / Raw Goods heading to sort its items (again to reverse, a third time for build order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it. The printed traveler always keeps the standard columns in build order.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard traveler with its header on every page. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • Excel saves the items (with their recorded quantities and tracking) and, when shown, the instructions.
