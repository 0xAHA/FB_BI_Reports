📖 How this report works

What it shows

Where a lot, serial number, expiry date or other tracking value was recorded: the receipts, shipments, work orders, picks and RMAs that carry it, with the order number. It is the BI version of the standard Tracking report and reads the same data the same way. (Tracking Detail is its sibling with the work orders' costs.)

The rows
  • Tracking is the tracking type (Lot Number, Serial Number…), Value its value: the serial number, else the text, else the number, else the date.
  • Order Details says what happened ("… received for PO:", "… shipped for SO:", "… consumed on WO:", "… picked for TO:", "… added to RMA:"), followed by the order number. Click the number to open the order.
  • One row per tracking value and serial number on each receipt, shipment, work order item, pick item and RMA item.
Using it
  • Type part of a tracking value and press Enter. Empty shows every tracking record. Search for exact value matches the whole value, numbers included.
  • Part and product numbers take % as a wildcard (RMAs are matched on the product only, as in the standard report). The Recorded on boxes leave out whole kinds of records.
  • Click a column heading to sort (again to reverse, a third time for the report's order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Settings → Reset column layout undoes it.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. Print prints those pages.
  • A very large result shows its first 10,000 rows with a Load all button (the standard report prints 1,000 at a time).
