📖 How this report works

What it shows

Where a lot, serial number, expiry date or other tracking value was recorded: the receipts, picks, shipments, work orders, sales orders and RMAs that carry it, with the order number. It is the BI version of the standard Tracking Detail report and reads the same data the same way.

The rows
  • Tracking is the tracking type (Lot Number, Serial Number…), Value its value: the date for a date type, else the serial number, else the text.
  • Order Details says where it was recorded ("… on PO:", "… Picked for SO:", "… Item on WO:"), followed by the order number. Click the number to open the order.
  • A work order row is followed by the work order: its finished part, status, dates, quantities and cost, and every item with its original, needed and used quantity, unit and total cost and tracking ("+" the finished good, "-" the items used).
  • Picks for work orders are left out, as in the standard report (the work order's own item rows show what it used): Include work-order picks lists them too.
Using it
  • Type part of a tracking value and press Enter. Empty shows every tracking record, as the standard default (%).
  • Work order details: under every work order row (the standard), once per work order (the first of its rows), or off.
  • Click a column heading to sort (again to reverse, a third time for the report's order); a work order's details move with their row. Drag a heading onto another to move the column; drag a heading's right edge to resize it. Settings → Reset column layout undoes it.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. Print prints those pages.
  • A very large result shows its first 10,000 or so rows (whole tracking records) with a Load all button.
