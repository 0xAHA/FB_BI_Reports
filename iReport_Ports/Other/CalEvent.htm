📖 How this report works

What it shows

What is on in a date range: calendar events, work orders, sales orders and purchase orders, each with its location, category, start and end dates, status and note. It is the BI version of the standard Calendar Report and reads the same data the same way.

Which dates
  • Calendar events: listed when they start, end or run across the range.
  • Work orders: Start is the date started (else scheduled to start), End the date finished (else scheduled); listed like events. The name is "WO" and the number.
  • Sales / purchase orders: Start is the date issued, End the first ship date; listed when the first ship date is in the range.
  • All dates still needs the date: an order without a first ship date is never listed, as in the standard report.
Using it
  • Filter changes apply straight away. The standard default, This month, shows only this month.
  • Include turns each kind on or off; the status boxes pick work, sales and purchase order statuses. Category narrows to one calendar category (purchase orders have none, so they drop out). MO # / SO # / PO # take an order number, with % as a wildcard.
  • Sort by, Show time, Show category colour, the column switches and Report title are the standard report's options.
  • Click a WO, SO or PO number to open it in Fishbowl.
  • Click a column heading to sort (again to reverse, a third time for Sort by's order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The view selector switches to Calendar: a month grid of the same rows. Events and work orders run across their days, sales and purchase orders sit on their first ship date, coloured by category. ‹ › change month; days outside the date range are shaded (change the range to load them). Pivot counts the rows by any two of type, category, status, location and the dates.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report (the Calendar view prints the table). Print prints those pages.
  • A very large result shows its first 10,000 rows with a Load all button.
