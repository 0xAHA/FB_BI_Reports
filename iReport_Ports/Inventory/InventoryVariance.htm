📖 How this report works

What it shows

For each part, every receive, shipment, consumption, yield, transfer and adjustment in the date range, with the part's quantity on hand at the start (Beginning Qty) and end (Ending Qty) of the range. Variance is Ending − Beginning. It is the BI version of the standard Inventory Variance report.

Reading the quantities
  • Quantities are in each part's own unit of measure.
  • Beginning and Ending Qty add up the chosen location groups' stock, from Fishbowl's running on-hand on the inventory log.
  • The listed events need not add up to the Variance: some Yield rows repeat a quantity another row already moved, and event types you leave out still change the stock. Unexplained shows by how much.
Unexplained

Unexplained = Ending Qty − (Beginning Qty + the events listed). Zero: the listed events account for the whole change. Anything else is highlighted; point at it to see what it is made of. Only parts with an unexplained difference (Filters) lists just those parts, in the table, pivot, PDF and Excel.

Why it usually isn't zero:

  • Moves inside a location group. A Yield or Transfer row records stock moving from one location to another. When both are in the same group (a pick, a bin move) the row shows the quantity moved, but the group's stock doesn't change. This is nearly always the reason: in one month of live data (three groups, the standard event types) it was the whole difference for 144 of the 146 parts that had one.
  • Event types not listed. Beginning and Ending count every event. A type you untick, Adjust UOM (off by default) or one the standard report never lists still changes the stock if it carries a quantity. On the live data Adjust UOM entries never did; Enable / Disable Tracking (listed) sometimes do.
  • Back-dated entries (the "Other" part). Beginning and Ending are the stock on the newest entry dated before the date. An entry made later but dated earlier carries the stock as it stood when it was made, e.g. a work order consumption entered on 1 April but dated 31 March, after that day's output was booked: Beginning already holds the output (−1,670 for that part).
  • Several location groups don't cause one: Beginning and Ending add the chosen groups up, and a move between two chosen groups lists both its rows.
Using it
  • Filter changes apply straight away.
  • Click a part's row to show or hide its events; Expand / Collapse do every part.
  • Click a part number to open it in Fishbowl.
  • Click the Action, Date, Location Group or Qty heading to sort each part's events (again to reverse, a third time for log order). Beginning Qty, Ending Qty, Variance, Unexplained and UOM sort the parts instead: Variance puts the biggest drops first, then the biggest gains. Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: total the event quantities (or count the events) by any two of part, location group, event type, date and UOM. Part × event type shows what moved each part's stock in the range. Click a figure to see the events behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result (a long date range) shows its first 10,000 or so events, whole parts only, with a Load all button. Every part shown has all its events and its true Beginning and Ending Qty.
