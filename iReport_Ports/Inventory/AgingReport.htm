📖 How this report works

What it shows

How old the inventory on hand is: every tag of stock, with when it was created and how many days ago that was. It is the BI version of the standard Aging Report and reads the same data the same way.

One row per tag set

Tags of the same part, in the same location, with the same tracking (lot, expiry…) are added together into one row. Created is the oldest of those tags; Days is the whole days since then.

Using it
  • Filter changes apply straight away.
  • Click a group's row to show or hide its tags; Expand / Collapse do every group.
  • A group row counts its tags and gives the oldest age in it. Grouped by part, it also totals the quantity.
  • Show location details adds a heading per location when grouped by location group. Off, the location isn't shown, as in the standard report.
  • Click a column heading to sort the tags within each group (again to reverse, a third time for the standard order): Days puts the oldest first. Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: total Qty, Days or the number of tag sets by any two of location group, location, part, UOM, age band (0–30, 31–60, 61–90, 91–180, 181–365, 366+ days) and Created. Part × age band shows how much of each part is how old. Click a figure to see the tags behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 or so tag sets (whole groups) with a Load all button; the group and total rows then cover the tags shown.
