📖 How this report works

What it shows

Every inventory part on hand, by location group and location, with a blank Count line to write in what you actually count. It is the BI version of the standard Cycle Count List (the Physical Inventory Worksheet) and reads the same data the same way.

A part with stock under several lots, use-by dates or other tracking has one line per combination, with its tracking shown.

Options
  • Zero quantity items: Show In Default Locations adds parts with none on hand in their default location (qty 0), so a count can confirm the zero. Show As 'Not In Inventory' lists parts with none on hand anywhere you picked, in a last group.
  • Show quantities on hand off gives a blind count: no Qty or UOM column.
  • Show serial numbers lists each serial number under its line.
Using it
  • Filter changes apply straight away.
  • Click a location group or location to show or hide its lines; Expand / Collapse do every location group.
  • Click a column heading to sort the lines within each location (again to reverse, a third time for the standard order); serial numbers stay under their line. Count and Tracking don't sort, and a blind count ignores a sort on quantity. Drag a heading onto another to move the column (the printed sheet follows); drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • A very large count shows its first 10,000 lines, cut back to whole locations, with a Load all button. Every location listed is complete; pick location groups or locations to count the rest.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • Print gives the count sheet. Under Printing in the filters you can start a new page for each location group or location, one per counter.
  • Quantities are in each part's own unit of measure.
