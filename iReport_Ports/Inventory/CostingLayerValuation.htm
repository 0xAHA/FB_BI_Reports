📖 How this report works

What it shows

The quantity and value of each part's cost layers: the batches Fishbowl keeps for FIFO / LIFO costing, one per receipt, build or adjustment. It is the BI version of the standard Costing Layer Valuation and reads the same data the same way.

Asset Value is what is left in the layer; Cost is that value per unit.

Which layers
  • Active layers still hold stock. Their total is the FIFO / LIFO value of what's on hand.
  • Fulfilled layers have been used up (quantity and value 0).
  • Voided layers were cancelled.
  • The date range is on when the layer was made. The standard default, This month, shows only this month's new layers: pick All dates for the value of everything on hand.
  • Show historical data shows each layer as it was made: its original quantity, cost and value.
Using it
  • Filter changes apply straight away. Show historical data only redraws; the other filters re-run the query.
  • Click a part's row to show or hide its layers; Expand / Collapse do every part.
  • Click a column heading to sort the layers within each part by it (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: total any figure (Asset Value, Qty…) by any two of asset account, part, status, date created (by day, week, month, quarter or year) and UOM; for example, how much value is still in layers made each month. Click a figure to see the layers behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 layers with a Load all button; totals then cover the layers shown.
  • The asset account is the part's inventory asset account, or your default inventory asset account when the part has none.
