📖 How this report works

What it shows

How much of each inventory part was on hand in each location group at the end of the chosen day, with an optional estimated value. It is the BI version of the standard On Hand By Date and reads the same data the same way.

For today it is the same as the current on-hand.

Where the numbers come from

Fishbowl records the running on-hand of a part in a location group every time stock moves. The report takes the last record on or before the end of the day.

  • Parts with no stock history before that day are not listed.
  • Quantities are in each part's own unit, so they are not totalled.
Cost

With Show cost on, Asset Value = unit cost × quantity, using today's cost:

  • Average: the part's average cost.
  • Standard: the part's standard cost.
  • FIFO / LIFO: the unit cost of the part's oldest / newest open cost layer, applied to the whole quantity.
Comparing two dates

Pick a Compare with day under Filters → Report date. The Comparison view then lists every part's on-hand at both days and the Change; the earlier day is always on the left, so a positive change means stock went up.

  • A part on hand at only one of the days is listed too, with its figure at the other day (usually 0).
  • With Show cost on it adds the value at each day and the value change. Both use today's cost, so the value change comes from the quantity change alone. Location groups and the Report Total add up the values.
  • Set Compare with back to No comparison to return to the standard table.
Using it
  • Filter changes apply straight away.
  • Click a location group's row to show or hide its parts; Expand / Collapse do every group.
  • Click a column heading to sort the parts within each location group (again to reverse, a third time for the standard order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The view selector switches between Table, Comparison (above) and Pivot. The pivot: total Qty, or with Show cost on Asset Value, by any two of location group, part, default vendor and UOM. Click a figure to see the lines behind it. Print, PDF and Excel follow the view on screen.
  • A very large result shows its first 10,000 part lines with a Load all button; totals then cover the lines shown.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • Totals add up the rows the report lists.
