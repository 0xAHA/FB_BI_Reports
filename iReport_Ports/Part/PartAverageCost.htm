📖 How this report works

What it shows

Every active part's average cost: the running average Fishbowl keeps as stock is received and used, and the quantity on hand that cost covers. It is the BI version of the standard Part Average Cost report and reads the same data the same way.

Which parts

Active parts whose average cost passes the cost test (by default, more than 0.00). A part that has never had an average cost (never stocked, or a service / non-inventory part) is never listed, as in the standard report.

Using it
  • Filter changes apply straight away. Part number takes % as a wildcard (BRK% = every part starting BRK).
  • Click a part number to open it in the Part module.
  • Click a column heading to sort (again to reverse, a third time for part order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Avg vs Std selector switches to a comparison: each part's standard cost next to its average cost, the difference and its %, and the stock valued at each cost, with totals. The subtitle names the company's costing method. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report. In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 parts with a Load all button.
