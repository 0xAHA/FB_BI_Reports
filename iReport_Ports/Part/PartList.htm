📖 How this report works

What it shows

Your parts in part-number order, with their description, the quantity on hand (in each part's own UOM, every location group) and today's cost. It is the BI version of the standard Part List and reads the same data the same way.

Cost

Average Cost is the part's average cost; Standard Cost the standard cost set on the part. FIFO Cost is the unit cost of the oldest cost layer still open, LIFO Cost of the newest; it is blank when the part has none. The company's own method is marked in the list.

Using it
  • Filter changes apply straight away. Part number and description take % as a wildcard (BOLT%, %steel%); without one they must match exactly, as in the standard report.
  • Only active parts are listed until you tick Inactive parts; untick both and nothing is listed.
  • The Show boxes switch the Description, Qty On Hand (with its UOM) and Cost columns on and off, as the standard report's options.
  • Click a part number to open it in the Part module.
  • Click a column heading to sort (again to reverse, a third time for the part-number order). Drag a heading onto another to move the column; drag a heading's right edge to resize it. Your layout is remembered; Settings → Reset column layout undoes it.
  • The Table / Pivot selector switches to a pivot: the on-hand value (Qty × the chosen cost), the part count, Qty or Cost by any two of part type, ABC code, UOM and active / inactive. Part type × ABC code shows where the stock value sits. Click a figure to see the parts behind it. Print, PDF and Excel follow the view on screen.
  • The App / PDF buttons in the header switch between this interactive view and the printable pages, laid out like the standard report (with its blank ruled column after the UOM). In PDF view pick the paper size and orientation in the bar above the pages; they are remembered. Print prints those pages.
  • A very large result shows its first 10,000 parts with a Load all button.
