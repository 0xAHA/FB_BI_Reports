📖 How to Use This Report

Filters

Click Filters to open the filter drawer above. Apply changes and click Apply to refresh the data.

Each table column also has its own filter row beneath the header — type to substring-search a text column, or pick a value for select columns. Text filters offer autocomplete from the live data.

Table
  • Sort — click a column header to toggle ascending → descending → off
  • Reorder — drag a column header sideways onto another column
  • Resize — drag the right edge of a column header
  • Open record — click any blue link cell to open the related Fishbowl module

Your column order, widths, and sort survive reload (saved to your Fishbowl user account).

Settings & debug

Settings persist to your Fishbowl user account. Tick Show debug console to open the bottom-of-page diagnostics drawer — drag its top edge to resize.

Admins can Publish the current state as the default for every user, or lock editing so non-admins can only view.
