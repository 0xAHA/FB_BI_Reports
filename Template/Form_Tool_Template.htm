📖 How this tool works

What it does

Counts one part's stock location by location and posts the new quantities to Fishbowl as a cycle count. Only untracked parts: a tracked part needs its tracking on every count line.

Using it
  • Type the part number and press Enter. Each location holding it is listed with its quantity on hand and committed.
  • Type the counted quantity in New count for each location you counted; leave the others alone.
  • Post count asks you to confirm the changes, posts them, then reads the stock back and shows it.
  • A count below the committed quantity is refused before anything is posted.
  • The button needs the Inventory › Cycle right.
