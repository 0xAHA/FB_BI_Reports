📖 Instructions

Layout
  • Click the padlock to unlock editing — drag a widget by its header, resize from any edge
  • Add Widget opens the picker (many widgets are picker-only and not on the default layout); Save Layout stores your personal arrangement
  • KPI badges in the header: drag to reorder, hover for ✕, + to add more
  • Admins (Fishbowl Admin access) can Publish the current layout/filters as the org-wide default and lock user editing
Filters & data
  • Location Group and Vendor (default vendor on the part) apply to every widget that supports them
  • The date range only affects movement/activity widgets — stock loss, cycle count, scrap, stock movements, received/shipped, inventory revenue, movement trend, and slow-moving velocity
  • Snapshot widgets (stock value, ABC, availability, below reorder, unavailable, days of cover, expiring lots, suggested reorders, negative inventory, fulfillment pipeline) always show the CURRENT position and ignore the date range — each widget's ⓘ tooltip says which kind it is
  • Click a Stock by Location Group bar/slice, an ABC slice, or a Stock Movements category to drill into the underlying rows; part and order numbers are links into the matching Fishbowl module
  • The drilldown modal supports search, column sorting and Export CSV
