📖 Instructions

Layout
  • Click the padlock to unlock editing — drag a widget by its header, resize from any edge
  • Add Widget opens the picker; Save Layout stores your personal arrangement
  • KPI badges in the header: drag to reorder, hover for ✕, + to add more
Filters & data
  • The filter strip offers a date range plus Vendor, Category, ABC code and Location — dimension filters apply to every widget
  • Date range: spend and receipt-history tiles (Monthly Spend, the KPI strip, Top Vendors, Purchases by Category, Recently Received, Lead Time Trend) honor it; PO Status uses the issued date
  • Snapshot tiles ignore the date range: Expected Receipts, Overdue POs, Pending Approval and the Receipt Calendar always show the current open PO book
  • Click a PO Status segment, a vendor or category, a Receipt Calendar week, or any PO # to drill into the underlying orders
  • Admins (Fishbowl Admin access) can Publish the current layout/filters as the org-wide default and lock user editing
