AFTER INSTALL - approve the app in Fishbowl
===========================================

The agent is installed and the Windows service has started. One step remains
before it can pull data: Fishbowl must approve it as an Integrated Application.

IMPORTANT - HOW THIS WORKS:
The app does NOT appear in Fishbowl until the agent has TRIED to log in and
FAILED once. That first failed attempt is what registers it. So the sequence is:

STEP 1 - The first login attempt fails (this is normal)
  On its first sync the agent will try to authenticate and FAIL with an
  "application not approved" error. This is expected - it is not a
  misconfiguration. The attempt is what makes the app show up in Fishbowl.

STEP 2 - Approve the app in the Fishbowl client
  Go to:   Setup menu  ->  Settings  ->  Integrated Apps tab
  The app now appears in the list (default name "PowerBI Agent", ID 200, or
  whatever name/ID you entered in the wizard). Select it, then click the green
  Approve button in the top-right corner.

STEP 3 - Nothing else to do
  No reinstall and no restart are needed. On its next scheduled sync the agent
  will authenticate automatically and begin pushing data to Power BI.

TO CHECK PROGRESS
  View the log file:
     C:\Program Files\Fishbowl Power BI Agent\agent.log
  Look for "Authenticated to Fishbowl REST API" followed by "sync ok".

  Re-open these settings any time from:  Start Menu  ->  Configure Agent
