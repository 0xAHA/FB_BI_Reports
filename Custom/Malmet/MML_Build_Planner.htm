MML Build Planner — how it works

Drop an MML CSV anywhere on the page. The sheet is rendered as it stands, each part is matched to Fishbowl for its live stock, and the planner works out which build quantities consume whole blanks of each raw material.

Reading the file

The structure is detected, not assumed, so a sheet that gains a column or a section still loads:

  • The title banner at the top is ignored.
  • Any row whose first cell is Part No. is a header. The row under it carrying Width / x / Length is folded into those headings.
  • A row with text in the first cell and nothing else is a section banner and is kept as a heading in the grid.
  • Blank and trailing junk rows are dropped. Anything skipped is counted, and you can list it from the status bar.
The Fishbowl columns

Each Part No. is matched to part.num exactly. A row that finds no part is tinted and counted — it is never quietly dropped.

Inventory is summed over the location groups you can access, using the same formulas as the other inventory reports, so the numbers agree: Available = On Hand − Allocated − Not Available + Dropship, floored at zero.

The planner

For a build quantity Q, each row needs Parts per Unit × Q parts, which take ceil(need ÷ Parts per Blank) blanks. Anything the last blank yields but you don't need is waste.

A row is exact when Parts per Blank divides the need evenly. The smallest quantity that does it is Parts per Blank ÷ gcd(Parts per Unit, Parts per Blank), and rows sharing a material are all exact together on any common multiple of those.

That perfect figure is shown when it is usable, but it is often in the millions — so the planner also scans real quantities and ranks them by waste. Click any suggested quantity to load it into the grid.

What is deliberately NOT used

The Blank Size and Scrap, Coil or Sheet columns are shown because the sheet shows them, but no material maths is derived from sheet or coil geometry. The calculation uses Parts per Unit and Parts per Blank only.

Rows carrying a note like “Offcut from …” or “Nested with …” are flagged in the planner, because their material comes from another part's scrap and counting them again would overstate what you need.
