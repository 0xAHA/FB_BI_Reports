📖 How this works

Capacity
  • Each location's fill is the volume (part length × width × height × quantity) or weight of its stock over its capacity. Switch with Volume / Weight; Units colours each location by its total quantity; 100 % is what the 95th-percentile location holds, so one bulk location doesn't grey out the rest.
  • A location's own custom fields set its capacity (Max Volume, or Height × Width × Length, and Max Weight); everything else uses the company default in Settings.
  • Hatched: a part there has no dimensions, so the volume shown is too low. Dashed: a rack slot with no location mapped to it.
  • Drag to rotate, ⟲ / ⟳ turn 90°, Iso / Top / Front. Scroll to zoom in on the point under the mouse; Ctrl-drag the floor, right-drag or Shift-drag to pan; double-click the empty floor (or a view button) to reset. The controls in the bottom-right corner pan, zoom, tilt and rotate step by step. Click a location for its contents.
  • Ctrl-click locations to select them (purple), then drag one of them onto another location: the Putaway tab proposes moving everything free in them there, one transfer order per source. Esc clears the selection.
  • Sort-order path draws the pick route in sort order and pins the locations that are out of sequence; it can suggest a renumbering and send it to Fishbowl's Locations import.
  • Press / to find a part (every location holding it lights up) or a location.
Putaway and replenishment
  • Putaway empties a location (or brings it down to the target fill). Each line goes to the part's default location, then to a location already holding it, then to the nearest location with space, in the order you leave switched on. Change any line's destination.
  • Replenish tops up default locations below the trigger from other locations holding the part: bulk / overflow first, then the largest lots.
  • Creating makes one Putaway transfer order per source location, issues it and sets each pick line's destination, then reads it back. Finish the pick in Fishbowl's Picking module (the Pick Ticket shows each destination).
  • After a putaway, the app offers to make each destination the part's default location in the group (Default-Locations import; needs Part › Edit Default Locations).
  • Only transferable stock moves: on hand, less committed, less started picks taking it.
  • Needs the Transfer Order › Edit and Issue rights and Picking › Edit.
Layout and mapping
  • Company editors (admin, or Edit Settings on this report) lay out racks and map locations to slots; everyone else sees them read-only.
  • Without a saved layout, a starter layout is worked out from your location names and sort order. Check it, then Edit and save.
  • Slots marked ? came from the sort order, not from a name: check them.
  • Slots are saved against the location's id, so renaming a location keeps its place.
  • Racks / Route switches what the Layout tab shows and edits. Edit layout starts editing; Done leaves when nothing changed, Save layout or Discard when something did.
  • A rack holding one location (a floor area, or an odd shelf like R1A2.1.2) can be stacked into another rack: select it while editing, then Stack into another rack… and pick the bay and position (below, between or above the locations there).
