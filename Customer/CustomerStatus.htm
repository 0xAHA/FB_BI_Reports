What saving does
Fishbowl exposes no REST verb that edits a customer, so each change is written as a one-row Customer import keyed on the customer's name. The import also requires the customer's default address on every row, so the address columns are sent back exactly as they were read — nothing else on the record is touched, because no other column is sent.

Rows are saved one at a time. If one fails, the rest still go, and the failure keeps its pending change so you can retry it.
