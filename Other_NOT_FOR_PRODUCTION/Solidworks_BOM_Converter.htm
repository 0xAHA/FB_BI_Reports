📖 How to Use This Tool

1 · Export from Solidworks

Export your Bill of Materials from Solidworks as a CSV file with:

  • Dotted indentation levels (1, 1.1, 1.1.1, 1.2, 2, 2.1...)
  • Part numbers, descriptions, quantities
  • Optional: vendor info, costs, UPC, dimensions
2 · Upload & Map Fields

Drag and drop your CSV file, then map Solidworks columns to Fishbowl fields in the popup dialog.

Required mappings:

  • Level — BOM hierarchy (1, 1.1, 1.2...)
  • Number — Part number
  • Description — Part description
  • Quantity — Component quantity

Optional but recommended: UOM, Vendor, Vendor Cost, UPC, Dimensions

3 · Configure Settings

Click the Settings gear (top right) to configure default UOM/Tax code, part creation type, validation, staged-BOM ordering, filename wrapping and the BOM Auto Create Type.

4 · Review BOM Structure

The tool displays a hierarchical tree with cost rollup, part-type badges (Finished Good, Raw Good, Stage), and per-assembly + grand total subtotals.

5 · Export or Import

CSV Export (manual): Export PPP (Part/Product/Vendor Pricing) and Export BOM for manual import.

Direct API (automatic): Create Parts and Create BOMs import directly via the Fishbowl API.

Import Order: Always create parts BEFORE BOMs. BOMs require all referenced parts to exist.
Tip: Settings & field mappings persist to your Fishbowl user account, and a Configuration File can move them between machines.
