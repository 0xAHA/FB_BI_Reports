BEFORE YOU INSTALL - set up Power BI first
==========================================

This agent pushes Fishbowl sales data to a Power BI streaming dataset. You must
create that dataset BEFORE finishing this install, because the configuration
wizard (which opens during setup) will ask you to paste its Push URL.

STEP 1 - Create the streaming dataset
  In app.powerbi.com:  your workspace  ->  + New  ->  Streaming dataset  ->  API

STEP 2 - Turn ON "Historic data analysis"
  This is essential. Without it, Power BI keeps only about one hour of data and
  you will not be able to build reports on your sales history.

STEP 3 - Add these columns (names must match EXACTLY, including spaces, $ and %):

  Text:      Order Number, Order Taken By, Customer Group, Account Manager,
             Customer Name, Product Category, Product Number,
             Product Description, UOM, Vendor, Batch Number
  DateTime:  Date, Expiry Date
  Number:    Day, Month, Year, Qty, Unit COGS, Unit Price, Total Price,
             Margin $, Margin %

STEP 4 - Copy the Push URL
  Open the dataset, go to the API Info tab, and copy the Push URL. You will
  paste it into the configuration wizard during this installation.

ALSO HAVE READY
  - Your Fishbowl server URL (for example  http://your-server:2456)
  - A Fishbowl username and password for the agent to log in with

You can change any of these settings later from:
  Start Menu  ->  Configure Agent
