📖 How to use this tool

The pipeline
  • Drop / browse a customer PDF (their purchase order). Images (PNG/JPG) work too.
  • Extract — a digital PDF's text is read instantly. A scanned page is sent to OCR automatically (or force it in Settings).
  • Parse — the header fields and line items are guessed and shown on the right.
  • Review — every field is editable. Fix anything the parser missed.
  • Match — click Match to Fishbowl to resolve the customer and each part number against the live database.
  • Create — builds the sales-order import and posts it to Fishbowl. The new SO number appears when it lands.
Good to know
  • This is a test / sandbox page. Always eyeball the parsed order before creating it.
  • PDF.js loads from the internet on first use (or from a self-hosted Fishbowl Script if one is deployed). OCR (Tesseract) is online-only.
  • OCR is slower (a few seconds/page) and less exact than a digital text layer. Prefer digital PDFs where you can.
  • Sales orders are created through Fishbowl's import mechanism (the same one QuickOrder uses), not a REST create — so the customer and part numbers must exist in Fishbowl.
  • Addresses are required by the SO import; the customer's ship-to / bill-to on file are used (pick them in the Match step).
