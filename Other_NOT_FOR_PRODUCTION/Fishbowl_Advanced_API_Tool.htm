Fishbowl Advanced API Tool

                
Feature guide

            

            
        


        
        


            

                
Authentication

                
    
                    
  • Enter App Name, App ID, username and password — App Name/ID persist across sessions
    • 
                    
  • Use Token ▾ to paste an existing Bearer token directly
    • 
                    
  • First-time app registration shows an approval notice (admin must approve in Fishbowl → Integrated Applications)
    • 
                    
  • Login errors show as persistent banners — click × to dismiss
    • 
                    
  • Selecting the Logout endpoint and clicking Send clears auth state, same as the Logout button
    • 
                

            


            

                
Idle Timeout

                
    
                    
  • After 10 minutes of inactivity an amber banner appears with a live countdown
    • 
                    
  • After a further 2 minutes the session is automatically logged out to free the Fishbowl concurrent-user licence
    • 
                    
  • Click Stay logged in or interact with the page at any time to reset the timer
    • 
                

            


            

                
Endpoint Sidebar

                
    
                    
  • All Fishbowl REST endpoints organised into collapsible category groups
    • 
                    
  • Live search filters by endpoint name or path
    • 
                    
  • Expand all / Collapse all buttons at the top
    • 
                    
  • The write-enabled Data Query (Write-Enabled) endpoint is hidden by default — it unlocks automatically if FbPartnerAPI=true is detected in your Fishbowl instance
    • 
                

            


            

                
Request Pane

                
    
                    
  • Path parameters — editable inputs appear for any {param} in the URL
    • 
                    
  • Query parameters — pre-populated per endpoint; add custom rows with + Add
    • 
                    
  • Custom headers — add arbitrary headers; Authorization and Content-Type are injected automatically
    • 
                    
  • Drag the divider bar between request and response to resize both panes
    • 
                

            


            

                
Body Editor & SQL Editor

                
    
                    
  • JSON body editor with syntax highlighting, Format, Copy, and Clear buttons
    • 
                    
  • Fields ▾ button — appears on POST endpoints that have body field schemas from the Fishbowl docs. Click to expand a table showing each field's name (indented by nesting depth), type, whether it is required or optional, and its description. Hover a query param key to see its description as a tooltip.
    • 
                    
  • SQL editor for Data Query endpoints — same highlighting, Format SQL, Copy, Clear
    • 
                    
  • Examples dropdown — 10 pre-built queries covering common integration scenarios (inventory, sales orders, purchasing, shipments, vendor parts). Add more by editing samplequeries.sql in the same folder
    • 
                    
  • SQL -- comments are stripped and whitespace collapsed before sending — the editor stays readable, the URL stays clean
    • 
                

            


            

                
Import / CSV Uploader

                
    
                    
  • Shown when an Import CSV endpoint is selected
    • 
                    
  • Choose the import type from the dropdown — headers are auto-fetched from the export endpoint and pre-filled as a template row
    • 
                    
  • Toggle between CSV / Text and JSON (Fishbowl 2D array) format; content is converted automatically when switching
    • 
                    
  • Drag and drop a .csv, .txt, or .json file to load it into the editor
    • 
                

            


            

                
Response Pane

                

                    

                        

                            Tab
                            Content

Other

                
    
                    
  • Request history — scrollable strip in the header; click any entry to reload it
    • 
                    
  • Debug console — collapsible panel at the bottom; logs all requests, responses, token events, and idle timeout activity
    • 
                    
  • Company branding — on login, company name and logo are fetched via Data Query and displayed in the title bar
    • 
                    
  • All settings (URL, token, username, App Name, App ID) persist in localStorage and restore on page reload
    •
