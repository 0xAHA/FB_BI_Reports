📖 How to Use Import Builder

1 · Drop a source CSV

Drag in an export from your source system:

  • Shopify products export → builds a Fishbowl PPVP (Part/Product/Vendor Pricing) CSV.
  • Shopify customers export → builds a Fishbowl Customer CSV.
  • Future: Xero contacts / items.

The tool guesses the source kind from the header row — you can override it via the dropdown next to the filename.

2 · Map fields

On first load, a mapping dialog pre-fills the obvious matches (e.g. Variant SKU → PartNumber). Required Fishbowl fields are marked *; you can't continue until they're mapped.

Your saved mappings are remembered per source shape, so the next Shopify-products import auto-applies them.

3 · Review and fix

The result table shows the Fishbowl-shape rows. Click any cell to edit; vocabulary columns (tax code, payment terms, carriers, ship terms, salesman, customer group) become dropdowns populated from your live Fishbowl data.

Column overwrite: the strip below each column header lets you bulk-set every (or just-empty) row in that column — typed value for free-text columns, dropdown pick for vocabulary columns. Apply scope toggles between "All" and "Empty only".

Mandatory cells with no value get a red wash; the row-status pill on the left switches to Issues until cleared.

4 · Export

Click Export Fishbowl CSV. The file uses the canonical Fishbowl column order for the chosen target (Customer / Vendor / PPVP), properly RFC-4180 quoted. Review it in a spreadsheet, then import via Fishbowl's File → Import → Import (or paste-import) UI.

Direct API push (one-click "create in Fishbowl") is on the roadmap — for v1 we round-trip via CSV for safety.

Tip: Settings (gear icon) persist to your Fishbowl user account via FBLib.Settings. Admins can publish them as the default for all users.
