Usage Guide

How It Works

This report uses Fishbowl's built-in Auto PO engine to calculate suggested purchase quantities for each part, factoring in on-hand stock, allocations, open orders, reorder points, and target levels.

Steps

  1. Configure parameters (vendor, location group, date range, etc.)
  2. Click Load Data to fetch suggestions from the system
  3. Review results — adjust quantities if needed
  4. Select/deselect parts using checkboxes
  5. Click Create PO on vendor header row to review and create a purchase order

Vendor Sections

Parts are grouped by vendor. Each vendor section can be collapsed or expanded using the > chevron toggle on the header row:

Expanded — part rows are visible beneath the vendor header.

Collapsed — part rows are hidden to save space.

Vendors with suggested order quantities auto-expand on load. Vendors with no suggestions auto-collapse. Toggling does not affect row selections, quantities, or PO values — collapsed items are still included when creating a PO.

Key Metrics

Available: On Hand − Allocated − Not Available + Drop Ship

Needed: Calculated shortfall quantity from the Auto PO engine

Order Qty: Suggested purchase quantity (editable per row)

ROP: Reorder Point — minimum threshold triggering a reorder

Target: Order Up To level — target maximum inventory

PO Value: Sum of (Order Qty × Last Cost) for selected parts per vendor

Company Wide vs Location Group Ordering

Fishbowl supports two reorder point models, controlled by the Location Group Reordering system property:

Company Wide (Location Group Reordering = OFF)

Each part has a single reorder point (ROP) and order-up-to level (OUL) that applies across all locations. Inventory is evaluated company-wide — aggregate on-hand across all warehouses is compared against one threshold. The Location Group filter is hidden.

Per Location Group (Location Group Reordering = ON)

Each part can have separate ROP/OUL values for each location group. Inventory is evaluated per-LG — on-hand at that warehouse is compared against that warehouse's thresholds.

When "All" is selected, the report runs company-wide first for the main row totals, then a supplementary per-LG scan identifies which specific warehouses need stock. When creating a PO you can choose Single PO (one order for total need) or Per Location Group (separate POs per warehouse).

The suggested order quantity per LG is calculated as: if Available < ROP, then order OUL − Available; otherwise no order needed.

Creating a Purchase Order

Click Create PO on a vendor's header row to open the PO modal. The modal shows all selected parts with editable quantities and costs.

Order Mode

When Location Group Reordering is enabled and "All" LGs is selected, the modal presents two order modes:

  • Single PO — creates one purchase order for the total suggested quantity. Use the Ship to dropdown to choose which warehouse receives the stock.
  • Per Location Group — creates a separate PO for each warehouse that has a shortfall. The dropdown switches to show only LGs with suggested quantities, and you can submit a PO for each one in sequence. Quantities are automatically capped so the combined total does not exceed the original suggestion.

If Location Group Reordering is disabled, or a specific LG is selected, the order mode selector is not shown and a single PO is created.

PO Status

At the bottom of the modal, choose the initial status for the purchase order:

  • Bid Request (default) — creates the PO with status Bid Request. Use this when you need to confirm pricing or availability with the vendor before committing.
  • Issued — creates the PO with status Issued. Use this when you are ready to send the order to the vendor immediately.

Review & Submit

  • Adjust any line item quantities or unit costs directly in the modal table before submitting.
  • The PO total updates in real-time as you edit.
  • Click Create PO to submit. The PO is imported into Fishbowl using the vendor's default carrier, remit-to address, and your selected ship-to location.
  • Once created, the vendor header row displays the new PO number as a link you can click to open it in Fishbowl.

Parameters

Vendor: Select a specific vendor or "All Vendors" (processes each vendor individually).

Location Group: Use "All" (-1) for company wide, or select a specific group. Only visible when Location Group Reordering is enabled.

QB Class: Use "All" (-1) for all classes, or select a specific QuickBooks class.

Date Range: The date window for demand analysis.

Default Vendor Only: Only show parts where this vendor is the default vendor.
